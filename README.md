# 华为智慧屏 3 · 学习答题守护 (HuaweiTVQuizLock)

专为华为智慧屏 3 定制的防沉迷学习锁屏应用：
- **初始家长密码**：`4444`（用于关闭守护或答题中途紧急放行）
- **定时弹题**：开启守护后每 `10` 分钟自动置顶弹出一道小学二年级选择题（内置 30 道语文、数学、英语题）
- **惩罚与解析机制**：答对立即放行继续看电视；答错立即锁定 `3 分钟`（180秒）并显示正确答案与详细解析，倒计时结束后自动切换下一道题，直到答对才放行
- **防逃逸机制**：拦截遥控器返回键（需输密码 `4444`），若在未答完题时按主页键（Home）退回桌面，后台守护服务会在 2 秒内自动将答题界面重新拉回最顶层
- **局域网网页后台（方案 A）**：守护运行时，手机或电脑浏览器直接访问 `http://智慧屏IP:8888`，即可在线导入/修改 JSON 题库、修改密码、调整间隔时间或一键远程解锁
